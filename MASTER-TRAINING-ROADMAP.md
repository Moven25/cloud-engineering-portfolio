# Master training roadmap

Goal: develop practical IT skills, obtain Security+, and progress toward mid-level cloud engineering. Target study cadence: two hours daily. A+ exams are not planned.

| Phase | Focus | Exit evidence | Status |
|---|---|---|---|
| 1 | A+ hardware, Windows, troubleshooting | Explain concepts and verified labs | Current |
| 2 | Help desk, networking, Linux, PowerShell | Independent troubleshooting and documented tickets | Planned |
| 3 | Security+ and IAM | Security labs and exam readiness; certification only after passing | Planned |
| 4 | AWS (primary), Azure fundamentals (complementary) | Secure network, compute, storage, monitoring and IAM deployment | Planned |
| 5 | Terraform, Python, Ansible, Git and CI/CD | Reproducible automated deployment and tests | Planned |
| 6 | Containers, Kubernetes, architecture | Resilience, security and cost decisions; capstone | Planned |

Apply for suitable entry-level IT roles as skills develop. AWS is approved as primary; later exams follow the approved strategy and readiness. Progress by demonstrated competence, not time alone. Use guided practice, independent troubleshooting, analysis and evaluation. Track actual lab evidence in [LAB-TRACKER.md](LAB-TRACKER.md). Keep private study notes separate from public evidence.

## Five-year curriculum (illustrative windows)

| Window | Focus | Exit evidence |
|---|---|---|
| Months 1–4 | A+ practical, Windows, ITSM, networking, Git, PowerShell | Diagnose basic unfamiliar faults and document tickets; apply early |
| Months 5–9 | Security+, Linux, IAM, Python, Bash, SQL, advanced networking | Independent troubleshooting and Security+ exam readiness |
| Months 10–18 | Primary cloud, security, FinOps, recovery | Secure deployment, restore test, cost forecast and cleanup |
| Months 19–30 | Terraform, Ansible, containers, CI/CD | Repeatable tested deployment and rollback |
| Months 31–42 | Migration, governance, SRE, platform engineering | Tested migration, SLOs, risk review and handover |
| Months 43–60 | Architecture, consulting, capstones, AI infrastructure | Defend engineering and financial decisions; target mid-level roles with experience |

Daily target: 30 minutes concepts, 60 practice, 15 assessment, 15 documentation. Adjust by proficiency; never delay suitable employment solely to finish the curriculum. A+ coursework only; Security+ first certification. AWS primary; Security+ then AWS Solutions Architect Associate, later exams conditional. See [competencies](COMPETENCY-MATRIX.md) and [assessment](ASSESSMENT-STANDARDS.md).
