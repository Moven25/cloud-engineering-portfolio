# CompTIA A+ Study and Lab Roadmap

## Goal
Build genuine entry-level IT skills using **CompTIA A+ Core 1 (220-1201)** and **Core 2 (220-1202)** coursework. No A+ certification exams are planned. Security+ is the first certification target, followed by cloud engineering; IAM remains a supporting skill.

## Learning workflow
1. Watch a Professor Messer lesson.
2. Review notes and explain key concepts in my own words.
3. Complete a relevant hands-on exercise when practical.
4. Answer review questions and revisit gaps.
5. Document **only work actually performed** using the [lab template](templates/LAB-REPORT-TEMPLATE.md).
6. Publish sanitized screenshots and results after review.

Not every lesson needs a standalone VM lab. Physical components require identification exercises, diagrams, or real hardware practice.

## Core 1 — 220-1201 (current focus)

- Virtualization and cloud computing
- Hardware and network troubleshooting

## Portfolio standards
- Clearly label exercises **guided** or **independent**.
- Explain the reasoning behind each step, not just the clicks.
- Preserve authentic dates, outputs, and observations.
- Remove sensitive information from screenshots.
- Do not present fictional customer tickets as real incidents.
