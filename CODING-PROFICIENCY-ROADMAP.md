# Coding proficiency roadmap
Planned practical engineering, not full-stack developer training. Learn code in context; estimates include exercises and existing labs, not extra hours on top of curriculum.
| Skill | Hours | Target |
|---|---:|---|
| Python | 120–160 | Level 4 practical automation and AI integrations |
| Terraform/HCL | 60–80 | Level 4 reproducible infrastructure |
| Bash | 35–50 | Level 3–4 Linux automation |
| PowerShell | 30–45 | Level 3 Windows automation |
| SQL | 25–40 | Level 3 queries and data validation |
| YAML/JSON | 15–25 | Level 4 configuration and troubleshooting |
| JavaScript/TypeScript | 15–20 | Level 2 reading/integration familiarity |
Total 300–420 hours (rounded planning range). Prioritize Python and Terraform; no simultaneous intensive language tracks.
Progression: read commands → variables/conditions/loops/functions → files/logs/errors → Git, tests and reusable scripts → REST/JSON/SQL → AWS SDK with least privilege → Terraform plan/state/modules/rollback → CI/CD and container configuration → secure AI APIs, retrieval, evaluation and deployment. Introduce PowerShell in Windows, small diagnostic scripts in networking, Bash in Linux, Python before AWS automation. JavaScript optional until integration requires it.
Use existing LAB-006, 062–069, 080–091 and 101–124. Each stage: explain code, modify it, debug an unfamiliar fault, test expected/error cases, review diff, document. Official docs allowed; AI-generated code must be understood, tested and reviewed for security. No secrets, destructive defaults or unapproved paid resources. Record assistance; independent gate without step-by-step or AI-generated solution, then AI-assisted review separately.
