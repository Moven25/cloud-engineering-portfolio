# Training challenge progression

| Stage | Coaching | Challenge |
|---|---|---|
| Foundations | Demonstration then guided practice | Explain, repeat, diagnose one fault |
| Early IT | Hints on request | Unfamiliar ticket, competing priorities, verify fix |
| Cloud | Requirements rather than recipes | Design and deploy within budget, test security and recovery |
| Automation | Independent build and review | Broken pipeline, rollback, incident timeline |
| Advanced | Simulated stakeholder panel | Ambiguous requirements, cost-quality tradeoffs, AI failure, executive defense |

Five hours/day, five days/week when feasible remains the target, not a minimum for every project. Multi-session projects and optional timed drills; no artificial pressure before readiness. Use existing assessment rubric and mandatory safety gates; private feedback, repeat weak areas, never publish grades. No paid deployment without approval. No unperformed labs completed.
